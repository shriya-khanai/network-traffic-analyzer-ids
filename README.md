# 🌐 Network Traffic Analyzer & Intrusion Detection System (IDS)

A Python-based networking project that analyzes network traffic and detects potentially suspicious activity using Scapy.

## 📌 About the Project

This project captures and analyzes network packets to help understand network behavior and identify possible security threats. It includes detection mechanisms and CSV-based logging for traffic analysis and IDS alerts.

## ✨ Features

- 📡 Network packet capture and analysis
- 🚨 Port scan detection
- 📈 Traffic spike detection
- 🔄 Repeated connection detection
- 🔐 Monitoring of suspicious ports
- 📝 IDS alert logging to CSV files
- 📊 Export of network traffic data for analysis

## 🛠️ Technologies Used

- Python
- Scapy
- Pandas
- Matplotlib
- Wireshark
- Npcap

## 🧪 Testing

The project includes test scripts for checking detection logic using simulated packets. These tests help validate the detection mechanisms without performing real network scans.

## 🎯 Learning Objectives

- Understand network packet analysis
- Explore common network security concepts
- Learn basic intrusion detection techniques
- Practice Python-based networking and testing

## ⚠️ Disclaimer

This project is intended for educational purposes. Only capture or analyze network traffic on systems and networks you own or have explicit permission to monitor.
